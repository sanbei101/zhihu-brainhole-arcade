## 📖 项目简述

**知乎脑洞游乐园** 是为 **知乎黑客松** 量身打造的策略向推演沙盘。

知乎最具辨识度的文化现象之一，便是硬核历史区与科幻区经久不衰的**高赞脑洞/历史假设问答**：

- _“如果赤壁之战曹操大获全胜，后来的天下格局会怎样？”_
- _“如果太阳熄灭前三天，全人类突然收到警报？”_
- _“如果白垩纪陨石与地球擦肩而过，恐龙能否孕育出智慧文明？”_
- _“如果秦始皇巡游途中得到了一份世界全图？”_

在过去，这些奇绝的想象仅仅是一篇篇静态的文字回答。而本项目将这些顶级“知乎脑洞神帖”转化为**人人可交互、步步有博弈的动态文字策略推演模拟器**：
玩家化身身处风暴漩涡的历史人物或领袖，面对各怀异心的 AI 朝臣、将领、异邦力量，做出关键抉择，推演独属于你的世界线演进，并在终局**自动收束为一篇数千字的“知乎体深度亲历长文回答”**

## ✨ 核心游戏玩法与机制亮点

```
                               ┌────────────────────────┐
                               │  选择脑洞副本 & 领袖角色 │
                               └───────────┬────────────┘
                                           ▼
                               ┌────────────────────────┐
                               │ Multi-Agent 议事厅博弈 │
                               │ (四方势力施压/交锋/通牒) │
                               └───────────┬────────────┘
                                           ▼
                               ┌────────────────────────┐
                               │ 四维分叉抉择 (A/B/C/D)  │
                               │ 🌟 D 项：群星风天命破壁  │
                               └───────────┬────────────┘
                                           ▼
                               ┌────────────────────────┐
                               │ 大势演进 / 四维增减 / 突变 │
                               └───────────┬────────────┘
                                           ▼
                               ┌────────────────────────┐
                               │ 结算即内容：生成知乎长回答 │
                               │ (谢邀开篇 / 卷目大纲 / 复盘)│
                               └────────────────────────┘
```

### 1. 🎭 AI Multi-Agent 多智能体博弈议事厅

- **鲜活的权力生态**：每局自动或预制生成 4 个独立利益立场的 AI Agent（文臣、大将、使者、商贾、工匠等），各自拥有公开诉求、行事手段、信任度阈值以及不可触碰的私密红线。
- **动态站队与当场回击 (Retort)**：Agent 面对玩家的决断会产生【支持】、【反对】、【交涉】、【借势】等截然不同的反应，并会在议事舞台上针锋相对、当场驳斥对手。
- **危机倒计时与最后通牒 (Ultimatum)**：当核心危机持续恶化或 Agent 信任归零时，将触发不可逆的最后通牒，逼迫玩家做出残酷抉择。

### 2. 🌟 梯度决策体系 & 【群星风】天命破壁飞升

每个回合分叉点，系统均会依据当前局势生成严格按阶梯分布的 **4 个互斥路线**：

- **A. 稳 (守正持重)**：在既有体制与惯性下的稳健举措，代价温和，收益可期。
- **B. 险 (铁腕强推)**：激进果决的政治清算或军事威慑，伴随内部阶层的剧烈震荡。
- **C. 赌 (利益置换)**：拆东墙补西墙的高风险权谋博弈，收益与代价尖锐对冲。
- **D. 狂 (🌟 天命破壁 · 群星式飞升抉择)**：
  - **知乎脑洞神髓**：打破正史枷锁与官僚俗见的天才破壁项（如：引墨家开启蒸汽实业纪元、焚江破釜挥师直捣建业、撕裂地幔引熔岩为火、远洋出海重造华夏秩序）。
  - **燃向宣誓语录**：自带 15~35 字极具宿命感与决绝气魄的群星风开篇金句，如：
    > _“烈火若能燃尽大江，便连天地一同烧透！”_  
    > _“天下若容不下汉室，汉室便去重造一个天下！”_  
    > _“若天空不再赐予光明，我们就把地核撕开当作篝火！”_

### 3. 🧠 In-Context Few-Shot 优质选项范本模仿引擎

- 游戏深度内置了连夜打磨的高质量剧本预制库。
- **少样本自适应模仿**：在进入第 2、第 3 回合由 AI 实时演变时，系统会将首回合高质量的 A/B/C/D 与群星金句作为 Few-Shot 样本注入 Prompt，**强制大模型对齐高水准的文风质感、信息密度与宣誓词史诗感**，解决长上下文下大模型质量滑坡与平庸化问题。

### 4. 📊 动态四维大势演化与大势熵增

- 玩家的每一个举措都在实时牵动四大核心国力指标：**【政权稳定】**、**【军心士气】**、**【民众支持】**、**【战略资源】**。
- **大势熵增机制**：随着推演回合递增，时代大势损耗逐渐加剧，逼迫玩家必须在有限时间内以大魄力破局，避免陷入坐以待毙的慢性崩盘。

### 5. 📜 结算即内容 —— 知乎体深度长文一键归档

- **通关即产出万字回答**：对局收束（辉煌胜利 / 悲壮崩盘 / 均势定鼎 / 惨胜）后，史官 AI 会站在玩家所扮演角色的当事亲历者视角，将整场世界线推演过程自动撰写为一篇**格式严整、文风硬核的知乎长文**：
  - **“谢邀”开篇破题**：以知乎标志性第一人称切入，交代历史关键节点的暗流涌动。
  - **卷目分章叙事**：逐卷复盘博弈交锋与关键抉择点。
  - **世界线终局复盘**：附带四维数据卡片、Agent 关系演变图谱与全过程分叉时间轴。
  - **社区一键分享**：支持一键复制 Markdown 格式长文与分享卡片，无缝发回知乎原帖讨论。

### 6. 🎨 复古像素美学 × 沉浸式世界动态换肤

- 纯前端 SVG / Canvas 像素精灵驱动，角色立绘随着发言情绪、思考状态呼吸起伏。
- **10 大世界专属色调与皮肤**：从秦汉的“玄黑青铜”、三国的“水墨青灰”，到深空的“天体异变”、赛博的“霓虹数据流”，全站根据题材自适应全局 CSS 变量与深色高对比度主题。

- **Node.js**：`>= 24`

## ⚡ 模型推荐配置 (强烈推荐 `deepseek-flash-4.1`)

本项目的世界线沙盘推演高度依赖**低延迟结构化输出 (Structured JSON)**。

在实测了众多大模型后，我**极力推荐使用 `deepseek-v4.1-flash`**：

- ⚡ **极致响应速度**：首字延迟低，多 Agent 连续表态与交锋演出丝滑流畅，无需玩家枯等。
- 🎯 **结构化遵循强**：完美契合 Zod Schema 严格约束与四维增量计算，少出现 JSON 格式损坏。
- 💰 **极致亲民成本**：推演整场多回合世界线兼万字知乎长回答更划算。

### 环境变量配置步骤

复制项目根目录下的 `.env.example` 为 `.env`：

```bash
cp .env.example .env
```

打开 `.env` 文件，选择以下任意一种方式配置你的模型端点：

#### 🌟 方式一：OpenAI 兼容中转站

```env
# 中转站 Base URL (需要带 /v1 后缀)
LLM_BASE_URL="https://api.your-relay.com/v1"
LLM_API_KEY="sk-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx"
LLM_MODEL="deepseek-v4.1-flash"
```

#### 方式二：DeepSeek 官方 API

```env
DEEPSEEK_API_KEY="sk-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx"
LLM_MODEL="deepseek-chat"
```

> **小贴士**：项目的模型适配层已内置 `jsonrepair` 容错修复与众多`json schema`自愈兼容机制，稳定性更佳。

## 🛠️ 技术栈与架构规范

本项目完全遵循现代前端工程与 Edge/Serverless 高标准构建：

| 领域 | 选型与规格 | 核心优势 |
| :--- | :--- | :--- |
| **全栈框架** | **Next.js 16 (App Router)** | 原生 React Server Components + Server Actions |
| **运行时** | **React 19** | 开启 Next 内置 **React Compiler** 自动记忆化 |
| **样式体系** | **Tailwind CSS v4** | 自适应黑暗模式 |
| **UI 组件库** | **shadcn/ui** | 基于语义化 Token 构建，低 className 冗余，高度无障碍体验 |
| **大模型框架** | **Vercel AI SDK** | 流式结构化调用，结合 Zod 保障 |
| **动效系统** | **GSAP** + CSS Keyframe Animations | 像素精灵情绪律动、打字机断句演出、全屏吸附微动效 |
| **代码工具链** | **oxlint** + **oxfmt** | 极致快速的代码静态检查与自动化代码格式化 |
