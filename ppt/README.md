## ⚡ 极速开始演播

本项目支持两种演播方式：

### 方式 1：单 HTML 独立离线演播（最推荐，无网环境可用）

已通过 Vite + `vite-plugin-singlefile` 将整套 React 演示文稿、样式、SVG 像素引擎、刘看山动态图与知乎徽标全部打入**单个完全自包含的静态 HTML 文件**：

- 文件路径：`ppt/dist/index.html`
- **使用方法**：直接在电脑上双击 `ppt/dist/index.html` 或用任何现代浏览器（Chrome、Edge、Safari 等）打开即可全屏演播，**不需要启动任何本地服务或联网**。

重新编译单 HTML 命令：

```bash
pnpm build:ppt
```

### 方式 2：在 Next.js 开发服务器中实时预览

在项目根目录启动服务后，直接访问：

```bash
pnpm dev
# 浏览器打开: http://localhost:3000/ppt
```

| 按键 / 手势                          | 动作说明                                                |
| :----------------------------------- | :------------------------------------------------------ |
| **`→` / `Space` / `PageDown` / `↓`** | 下一页幻灯片                                            |
