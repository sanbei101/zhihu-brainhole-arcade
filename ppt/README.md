## ⚡ 极速开始演播

本项目支持两种演播方式：

### 方式 1：单 HTML 独立离线演播（最推荐，无网环境可用）

已通过 Vite + `vite-plugin-singlefile` 将整套 React 演示文稿、样式、SVG 像素引擎、刘看山动态图与知乎徽标全部打入**单个完全自包含的静态 HTML 文件**：

- 文件路径：`ppt/dist/index.html`
- **使用方法**：直接在电脑上双击 `ppt/dist/index.html` 或用任何现代浏览器（Chrome、Edge、Safari 等）打开即可全屏演播，**不需要启动任何本地服务或联网**。

重新编译单 HTML 命令：

```bash
pnpm build:ppt
```

### 方式 2：在 Next.js 开发服务器中实时预览

在项目根目录启动服务后，直接访问：

```bash
pnpm dev
# 浏览器打开: http://localhost:3000/ppt
```

| 按键 / 手势                          | 动作说明                                                |
| :----------------------------------- | :------------------------------------------------------ |
| **`→` / `Space` / `PageDown` / `↓`** | 下一页幻灯片                                            |
| **`←` / `PageUp` / `↑`**             | 上一页幻灯片                                            |

1. **P01 封面：一句“如果”，值得用一整个世界来回答**
   - 动态像素舞台 + 刘看山挥手 + 赛博青铜徽标 + 决赛答辩定调。
2. **P02 立意与知乎生态共振：从单向长文到动态演化沙盘**
   - 直击知乎历史/科幻区“假设题”痛点；展示 4 步闭环飞轮（选题 ➔ 博弈 ➔ 决策 ➔ 万字知乎长回答一键发帖）。
3. **P03 美学与工程：纯前端程序化像素引擎 × 10 大平行宇宙换肤**
   - 突破重度美术包袱：`frameToPaths` 路径合并算法减少 85% DOM 节点，锁死 60fps；手绘 5 类微部件组合上百立绘，6 种情绪律动。
4. **P04 多端极致适配：桌面端三栏战局 × 移动端单手掌控**
   - 桌面端全景战术沙盘；移动端流式卡片与 `dvh` 视口适配，大拇指黄金热区排布。
5. **P05 提示词工程突破 1：严苛的三段式前缀缓存 (Prefix Caching) 架构**

6. **P06 提示词工程突破 2：情景真实度与 In-Context Few-Shot**
   - Agent 利益红线（Red Line）与通牒逼宫；首轮高水准选项作为样本动态注入（Few-Shot 范本模仿）；🌟 D 项群星风天命破壁与燃向宣誓金句。
7. **P07 游戏机制：四维国力动态博弈 × 大势熵增定律**
